我的第一篇博客

从零搭建一个属于自己的小天地

大家好，欢迎来到我的博客！这是我的第一篇文章，想记录一下我是怎么一步步把这个小天地搭起来的。

为什么想搭博客？

作为一名警校大一新生，平时除了训练和学习，总想找个地方记录点什么——训练的点滴、学到的知识、对未来的思考。朋友圈太碎片化，备忘录又太私密，于是萌生了一个想法：搭一个属于自己的博客。既能练练技术，又能沉淀自己。

踩过的坑

说干就干，我选择了 Hexo 框架 + GitHub Pages 的零成本方案。听起来简单，但过程可没那么顺利：

1. 环境准备就卡住了

第一步装 Git 就折腾了半天。装完之后在 PowerShell 里输入 git --version，结果直接报错：“无法识别 git 命令”。后来才明白，原来是安装窗口是在装 Git 之前打开的，PowerShell 根本不知道 Git 已经装好了。关掉重开一个窗口，问题就解决了。

2. 初始化项目遇到报错

接着执行 hexo init myblog，又碰到 FATAL Something's wrong... 的报错。查了半天，发现是 Node.js 环境的问题，重新配置好环境变量后，总算顺利跑起来了。

3. 第一次看到 Hello World

当浏览器里终于弹出 localhost:4000，页面上显示 “Hello World” 的那一刻，真的很有成就感。虽然只是一个默认页面，但感觉自己的小天地已经迈出了第一步。

接下来想做什么？

博客搭好了，接下来打算：

  • 坚持记录：把警校生活的点滴、学到的警务知识和法律常识都写下来
  • 继续折腾：学习 C 语言开发，研究渗透测试，让博客成为我的技术成长记录
  • 未来愿景：希望毕业后能回到青岛，成为一名合格的人民警察，用这个博客记录我的从警之路

写在最后

搭建博客的过程虽然踩了不少坑，但每一步都是成长。就像警校的训练一样，没有白流的汗，没有白踩的坑。希望这个博客能陪伴我走过大学四年，见证我从一名警校生成长为一名真正的人民警察。

感谢你的到来，我们下一篇见！
