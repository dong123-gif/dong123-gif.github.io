blog基础使用2.0

结合你之前用 Hexo 搭博客的情况，给你梳理一下怎么找到并更新你的博客：

找到你的博客

你的博客是基于 Hexo + GitHub Pages 搭建的，访问地址就是你当初在 GitHub 上创建的仓库对应的 Pages 链接，格式通常是  https://你的用户名.github.io 。直接在浏览器输入这个地址就能看到。

如果想管理后台，登录 GitHub 账号，找到你创建的博客仓库（比如  myblog ），所有文章源码都在里面。

更新博客的完整流程

  1. 进入博客目录：在电脑上打开终端，切换到你的博客文件夹，比如  cd D:\myblog （就是你之前初始化的那个目录）。
  2. 创建新文章：执行命令  hexo new “文章标题” ，会在  source/_posts  文件夹下生成一个对应的  .md  文件。图
  3. 编写内容：用记事本或 Typora 等编辑器打开这个  .md  文件，用 Markdown 语法写文章内容并保存。
  4. 本地预览（可选）：运行  hexo clean && hexo g && hexo s ，浏览器访问  http://localhost:4000  可以先预览效果。
  5. 部署上线：确认没问题后，执行  hexo d （部署命令），GitHub Pages 会自动重新生成并更新你的博客。稍等一两分钟，刷新你的博客网址就能看到新文章了。图

小提醒：部署前记得先在博客目录下用  git  提交代码，确保本地修改同步到了 GitHub 仓库，这样部署才能生效。

如果哪一步卡住了，随时把报错发给我，我帮你看。
